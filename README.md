# Bobber & Brine

An idle fishing game in a single HTML file. Open `index.html` in a browser to play.

- **Cast** by tapping the water (or pressing Space). Reel in while the bobber dips for a perfect catch worth ×3.
- **Tackle** upgrades raise catch value, bite speed, rare-fish odds and double-catch chance.
- **Crew** deckhands fish for you nonstop, including up to 8 hours while you're away.
- **Waters**: six fishing spots from Farm Pond to the Midnight Trench, each with six species to log.
- **Retire** to earn Fame stars (+10% income each) and start a new career.

Progress saves automatically in your browser's local storage.
